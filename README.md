# Threads 상태 확인과 답글 처리 자동화

> 이 저장소는 실제 인턴 및 별도 프로젝트 경험을 설명하기 위해 새로 작성한 공개 포트폴리오입니다. 회사의 원본 소스, 데이터베이스, 고객 정보, 운영 설정, 인증정보를 포함하지 않습니다. demo.py와 예시 데이터는 2026년에 처음부터 작성한 독립적인 오프라인 재현 예제로, 2024년 실제 운영 코드를 복제하거나 당시 배포 사실을 증명하지 않습니다.

**공개용 데모:** 실무 경험을 바탕으로 2026년에 별도로 구현한 데모입니다. 회사 내부 자료와 원본 코드를 보호하기 위해 가상 데이터를 사용했으며, 2024년 실무 구현과 공개 데모의 검증 범위는 구분합니다.

**기간:** 인턴 말기 및 2024.10 초 파일 수정  
**실제 업무 기술:** Python, Selenium, MySQL, Google Sheets 연동

## 배경과 해결하려던 문제

별도 소셜 채널의 존재와 활동 여부를 확인하고 후속 응답을 관리하는 과정에서 반복 검토가 필요했습니다.

## 직접 수행한 작업

- Threads 계정 존재 여부와 게시물 활동 확인 스크립트를 구현했습니다.
- 답글 처리와 결과 기록을 자동화하는 기능을 작성했습니다.
- 실패 대상 식별 및 결과 내역 관리 로직을 구성했습니다.
- 자동 답글의 맥락 오판 가능성을 검토해 수동 판단이 필요한 조건을 정리했습니다.

## 기여 범위 및 사실 확인

관련 코드 일부의 최종 수정일이 2024년 10월 초라 정확한 인턴 기간 내 완료 범위는 미확정입니다. 실제 게시글과 DM 문구, 대상 계정 및 내부 운영 주기는 공개하지 않습니다.

## 공개 오프라인 데모

가상 게시글의 위험 표현을 검사해 자동 발송 대신 사람이 확인할 항목을 표시합니다. 실제 Threads에 접속하지 않습니다.

```bash
python demo.py
python -m unittest discover -s tests -v
```

Python 3.10 이상을 권장합니다. 외부 API 키나 실서비스 계정이 필요하지 않습니다.

## 실행 가능한 응답 검토 큐

`review_queue.py`는 가상 메시지에서 중복을 제거하고, 응답을 바로 게시하지 않고 담당자의 확인을 받도록 구성한 SQLite 기반 데모입니다. 상태 전이와 기록, 잘못된 배치 롤백을 테스트할 수 있습니다.

```bash
python review_queue.py
python -m unittest discover -s tests -v
```

[응답 처리 흐름](docs/REVIEW_FLOW.md). 실제 Threads로 게시하거나 회사 운영 규칙을 공개하지 않습니다.
