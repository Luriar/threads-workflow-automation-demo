# Threads 스타일 응답 관리 데모

인턴 과정의 Threads 상태 확인과 답글 자동화 경험을 바탕으로, 2026년에 개인적으로 새로 만든 사람 검토 우선 모형입니다.

흐름: 가상 메시지 → 중복 검사 → 맥락 위험 검토 → 수동 검토 대기 또는 에스컬레이션 → 담당자 승인/거절 → 감사 이력.

- 실제 Threads 또는 Instagram에 접근하지 않습니다.
- 승인 결과는 승인된 **초안 상태**로만 기록하며 실제 댓글을 발행하지 않습니다.
- 위험 키워드는 단순 교육용 예시입니다. 실제 회사 정책이 아닙니다.
- 내용에 오류가 있으면 같은 입력 배치는 전부 롤백됩니다.
- 기존 작업 문서의 실서비스 ID, DM 문구, 운영 정책은 공개하지 않습니다.

실행: python review_queue.py
테스트: python -m unittest discover -s tests -v
